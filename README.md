# Relay

Self-hosted bridge from short-form video (Instagram Reels, YouTube Shorts) to structured Notion pages — evidence-grounded extraction, BYOK, fully local media processing.

Relay downloads media with host `yt-dlp`/`ffmpeg`, transcribes and translates audio through your own AI provider keys, routes content through dynamic extraction agents that must cite timestamped transcript evidence for every claim, and publishes structured pages to your Notion workspace via OAuth.

## Stack

| Layer | Technology |
| --- | --- |
| Runtime | **Bun** (everything runs through `bun` / `bunx --bun`; Next is started with `bun --bun`) |
| Frontend | Next.js App Router, Tailwind CSS v4, ShadCN UI (mira/zinc/emerald preset), HugeIcons |
| Backend | Hono mounted at `/api/v1/*` inside the App Router |
| Database | Drizzle ORM over Bun-native `bun:sqlite` |
| Validation | Zod at every API boundary |
| Observability | OpenObserve (server logs + client RUM) |
| Lint / Format | Biome (`tsc --noEmit` for type checking only) |

## Getting started

```bash
bun install

# Configure environment
cp .env.example .env.local
# Generate the credential-vault encryption key and set VAULT_KEY:
bun -e "console.log(crypto.getRandomValues(new Uint8Array(32)).toHex())"

# Run database migrations (generated by drizzle-kit)
bun run db:migrate

# Start the dev server
bun run dev
```

The app serves at `http://localhost:3000`; API health check at `GET /api/v1/health`.

## Configuration

**`src/config/index.ts` is the single source of all configuration.** Every env var is read there and consumed as `import config from "@/config"` — never read `process.env` elsewhere. See `.env.example` for the full variable list (`VAULT_KEY`, `DATABASE_URL`, OpenObserve credentials, ...).

Credentials at rest (`access_token` / `refresh_token`) are AES-256-GCM encrypted via WebCrypto with a unique IV per record; `meta_data` stays plaintext JSON for queryability. Tokens are never logged.

## Project layout

```
src/
  app/            Next.js routes; Hono API under app/api/v1/[[...route]]
  components/     React components (ShadCN UI in components/ui)
  config/         Single source of app configuration
  lib/
    db/           Drizzle schema + bun:sqlite connection
    observability/  OpenObserve logger, middleware, client RUM
    crypto.ts     AES-256-GCM vault encryption (WebCrypto)
    schemas.ts    Shared Zod validation schemas
drizzle/          Generated SQL migrations
public/           Static assets (served from the site root)
```
